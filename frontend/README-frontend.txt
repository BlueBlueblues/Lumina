光影志 · 网站打包说明
==============================

一、怎么打开
------------
1. 解压后双击 index.html，用 Edge 或 Chrome 打开即可。
2. 只把 index.html 单独拿走也能正常打开——图片、字体、样式、脚本全部在这一个文件里。
   src/ 和 README 是给修改时参考的，不影响浏览。
3. 不需要联网，不需要本地服务器。

二、这个包里有什么
------------------
index.html         完整网站（单文件，约 6.3 MB）
src/koi_back.webp  锦鲤池背景：水面与锦鲤层
src/koi_front.webp 锦鲤池背景：睡莲、黄叶、纸边前景层
src/koi_style.css  背景与页面排版的源码（便于阅读和修改）
src/koi_runtime.js 背景视差、萤火、页面切换的源码
README.txt         本说明

注意：index.html 是“已构建”的成品，CSS/JS/图片/字体都以 base64 内嵌在里面。
要改样式或交互，直接搜索 index.html 里的 <style> / <script> 即可；
src/ 里的文件是同一套源码的可读副本，方便对照，不会被 index.html 自动加载。

三、页面结构
------------
封面 → 首页 / 概览 → 记录 / 回看 / 档案
- 记录：两张入口卡（先拍一张 / 只想说几句）
- 回看：时间范围、空状态
- 档案：心情与地点统计
- 首页、记录、回看、档案使用同一张锦鲤池背景；鼠标移动时背景两层有轻微视差。首页底部原有的水彩树花装饰已移除，四个页面底部留白一致，桌面端不再出现页面比视口长一截的情况。
- 示例：12 条写实记录；配图来自 photo/ 的 Burst 免费商用高清照片（2000px 原图，构建时内嵌 900×506 无水印 WebP）。
- 开场视频已裁掉底部约 7% 的画面，去掉了「可灵 AI 4.0」水印；标题页与正文布局不受影响。

四、字体
--------
标题：Noto Serif SC（已子集嵌入，字体名 Lumina Serif）
正文：HarmonyOS Sans SC（已子集嵌入，字体名 Lumina Sans）
因此换一台没装这两款字体的电脑，打开也会和原机一致。
如果以后要换字体，替换 index.html 里 <style id="font-style"> 中的 @font-face 即可。

五、兼容性
----------
- 推荐 Chrome / Edge 最新版；Safari、Firefox 也可打开。
- 手机端会自动单列，背景为竖屏裁切。
- 关闭了“减少动态效果”的系统设置时，背景动画会停用（这是有意的无障碍处理）。

七、本次修改（2026-11-14）
--------------------------
改动都在 index.html 这一个文件里，src/ 没有动。

1. 删掉了 <style id="window-style"> 后面一个不可见的 UTF-8 BOM 字符。
   这个字符让紧跟其后的 .winScene 规则整条失效（选择器变成了 “﻿ .winScene”），
   于是 .winOutside 的 inset:-9% 溢出到视口外，封面因此多出 74px 竖向滚动条，
   右边缘还缺了一条背景。现在封面 scrollHeight 与视口一致，滚动条消失。
   注意：这也让封面背景的裁切回到 CSS 原本写的 “9% 余量” 构图，画面比之前略微收紧。

2. 移动端记录弹窗（照片/心情）的关闭按钮，从绝对定位改成 float，
   不再在单列布局里掉到弹窗中间。

3. 统一弹层关闭逻辑：新增 closeRecordOverlay()，
   ×、点遮罩、Esc、第一步的“取消”都走它；关闭时重置两张纸的状态，
   并把焦点还给打开它的那个按钮。Esc 现在只关最上面一层。

4. 心情滑杆重开时补齐 ARIA：aria-valuenow / aria-valuetext 会跟着视觉一起
   回到“未标注”（之前屏幕写“未标注”、读屏却读“60，偏雀跃”）。

5. 可点击行/入口卡补上键盘焦点：.rrow/.trow/.hrow 用内阴影，
   .entry/.tCard 用 2px 描边（原先四处都是 outline:none，Tab 过去看不见）。

6. 记录页两张入口卡的行动按钮统一贴到卡片底部（原先差 330px）。

7. 保存页默认选中“你说的”，AI 整理的那段改成可选项。

8. 照片步骤里原来有两个“跳过拍照”：拖拽区里的“先不拍”和底部的“不拍照，直接写”。
   查过代码后发现两者都调用 openTextSheet()，是同一个动作，
   所以删掉拖拽区那个，只留底部的主按钮。

9. 可读性：回看页的纸雾加厚；档案页的说明区改成一层纸底卡片，
   锦鲤就不用整屏洗白。封面底注、步骤标签、对话署名等 9–10.5px 的字号抬了一档。

10. 触控尺寸：移动端导航 44×44，“⋯”36×36，页面按钮最小高度抬到 44。

十一、第四轮：全站纸纹
----------------------
在最上层盖了一层 6% 的噪点（multiply），白卡和照片一起变成“印在纸上”的质感。

    body::after{
      content:""; position:fixed; inset:0; z-index:9999; pointer-events:none;
      opacity:.06; mix-blend-mode:multiply;
      background-image:url("data:image/svg+xml,...feTurbulence baseFrequency='.85'...");
    }
    body[data-screen="cover"]::after{opacity:0}

- 用的是封面 .winVeil::after 同一套噪点，不额外加素材、不增加文件体积。
- 封面自己已有 4.5% 的噪点，所以对封面关掉，避免叠到 10% 显脏。
- 弹层、Toast、菜单也会被盖住，这是想要的效果（统一材质）。
- 强度在 3%–9% 之间可调：3% 几乎看不出，9% 开始像滤镜，6% 是中间值。

想调强度：改 body::after 里的 opacity 一个数即可。
想彻底去掉：删掉 body::after 和 body[data-screen="cover"]::after 这两条规则。

十二、第五轮：封面标题换成书法体
--------------------------------
1. 封面标题用了一个字体族 "Lumina Brush"：已把「光影志」三个字从
   华文行楷裁成 1972 字节的子集，base64 内嵌在 index.html 里。
   任何机器打开都一样，不依赖本机装没装行楷。
2. 封面标题：clamp(56px,9.4vw,124px)、字重 400（书法体不要合成加粗，
   加了 font-synthesis:none）、字距 .02em。原来宋体 500 / 76px。
3. 其它屏的标题仍是宋体，没动——书法体只用在封面。

注意：子集只有「光影志」这三个字。以后改封面标题的文字，新字会回落到宋体，
需要重新裁一次子集（裁切脚本的做法：读 TTF 的 cmap 取字形、剥掉 hinting 指令、
重建 glyf/loca/hmtx/cmap/name，字形按 4 字节对齐，cmap 的 searchRange
和 idDelta 都要按子集的字形号重算）。

十三、第六轮：左上角字标重做
----------------------------
原来的字标是三件套：一枚细圆环里点一颗金点 + 宋体 17px + 下面一行 8px 的
LUMINA JOURNAL。三个元素三个语系（几何图标 / 中文衬线 / 拉丁全大写），
互相之间没有关系，看起来像拼上去的。

现在只留三个字：
    .brand b{ font-family:var(--serif); font-size:18px; font-weight:600;
              letter-spacing:.2em; color:var(--ink); text-indent:.2em; }
- 去掉圆环 mark 和 LUMINA JOURNAL 那一行（4 个屏幕各有一次，已从 HTML 移除，
  .mark / .brand span 的样式也一起删了，没有留死代码）。
- 字距 .2em 是刻意的：三个字拉开一点才像报头，紧排会像正文。
- text-indent:.2em 抵消末尾那个字距，让左边缘和下面的内容对齐。

顺手把 favicon 换成同一套语言的「墨底纸字」小方印
（深墨底 + 宋体「光」），原来那个圆环在新版里已经不存在了。
