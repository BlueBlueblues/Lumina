# 光影志 · 前端交接说明

> 本仓库已完成接入：`backend` 实现了 `/api/lumina` 的 5 个接口；前端 `Providers` 已切到 `mode: 'http'`，失败时自动回退本地规则；`src/lumina-bridge.js` 负责 localStorage → IndexedDB → 云同步。云同步入口在「运行状态 → 云同步设置」。

给接入后端的同学。这份说明只讲「文件怎么用」和「后端要提供什么」，不涉及实现细节。

---

## 一、怎么打开

**双击 `index.html`。** 不需要服务器、不需要联网、不需要装任何东西。

图片、视频、字体全部以 base64 内嵌在这一个文件里（约 6.3 MB），所以：
- 换任何一台电脑打开，看到的都和你这边一模一样；
- 第一次打开会有 1～2 秒的解析时间（要读完 6.3 MB），属正常。

推荐 Chrome / Edge。Safari、Firefox 也能开。

---

## 二、目录

```
index.html        完整网站（单文件，唯一需要看/改的文件）
README.txt        页面结构、配色、字体、历次改动的记录
接入说明.md        本文件
src/              背景图、CSS/JS 的可读副本

```

想改样式或交互，直接在 `index.html` 里搜 `<style>` / `<script>`，不要动 `src/`。

## 三、现在后端是模拟的

所有「读图 / 写文字 / 追问 / 整理」都经过页面里一个叫 `Providers` 的对象（`window.Providers`）。
默认 `mode: 'mock'`，用本机规则算，不联网。

**切换成真后端**：在 `index.html` 里搜 `const cfg = {`，改成：

```js
const cfg = {
  mode: 'http',              // mock → http
  endpoint: '/api/lumina',   // 指向你的服务
};
```

切过去以后，前端会按下面这 5 个接口调你的服务；任何一个返回非 2xx，页面会走兜底文案并在控制台报错，不会白屏。

---

## 四、后端需要提供的 5 个接口

都接受 `POST`，`Content-Type: application/json`，返回 JSON。

| # | 路径 | 请求体 | 期望返回 |
|---|---|---|---|
| 1 | `{endpoint}/observe` | `{ image, iso }` | `facts` 对象（见下） |
| 2 | `{endpoint}/write` | `{ facts, mood, note, stage, ... }` | `{ "text": "…" }` |
| 3 | `{endpoint}/text/reply` | `{ turns, mood }` | `{ "reply": "…", "question": "…" }` |
| 4 | `{endpoint}/text/integrate` | `{ turns, mood }` | `{ "text": "…" }` |
| 5 | `{endpoint}/photo/question` | `{ facts, mood, note }` | `{ "question": "…" }` |

### 各接口说明

**1. `observe`** —— 看图，返回画面事实。
- `image` 是 **dataURL**（`data:image/jpeg;base64,...`，1280 宽，约 100–300 KB），需要一个 `data:` 前缀摘掉再解码。
- `iso` 是拍摄时间（ISO 8601）。
- 返回的 `facts` 结构（字段名要保持一致，页面按这个渲染）：

```json
{
  "scene": "窗边的餐桌",        // 场景
  "time": "上午",               // 时辰
  "light": "均匀的灰白天光",     // 光线
  "subjects": ["吐司", "盘子"],  // 画面里有什么
  "absence": ["画面里没有人"],   // 画面里没有什么
  "text_spans": [],             // 画面里识别到的文字，没有就空数组
  "palette": ["#c9a27a", "#8d9b9c"],  // 主色（5 个以内）
  "brightness": 0.62,           // 0–1
  "saturation": 0.34,           // 0–1
  "conf": 0.78                  // 0–1，置信度
}
```

**2. `write`** —— 把事实写成一段话。
- 请求体在 `facts / mood / note` 之外还带 `stage`：
  - `stage: 'draft'` —— 先写一段草稿；
  - `stage: 'memory'` —— 找相似的旧时刻，前端会调用 **3 次**（带 `variant: 0/1/2`）；
  - `stage: 'final'` —— 用户补了一句之后重写。
- 返回 `{ "text": "…" }`。

**3. `text/reply`** —— 纯文字流程里，接住用户说的话。
- `turns` 是对话数组：`[{ "role": "me" | "it", "text": "…" }]`；
- `mood` 可能为 `null`；
- 返回 `{ "reply": "…", "question": "…" }`，`question` 用来追问一句，可以给空串。

**4. `text/integrate`** —— 把用户说的几段整理成一段。
- 同上 `turns`；返回 `{ "text": "…" }`。

**5. `photo/question`** —— 看图之后追问一句。
- 返回 `{ "question": "…" }`。

### 几条注意

- **不要把密钥放前端**：现在前端只调 `endpoint` 这一个自家地址，模型密钥应该在服务端。
- 接口返回的文案会直接渲染进页面，中文、换行都支持；前端做 HTML 转义，不用你处理。
- 响应慢没关系（前端有等待态），但建议控制在 3 秒内。

## 五、数据存在哪

**浏览器 localStorage**，key 是 `lumina.records.v3`，一个数组，新的记录在前面。

单条记录的主要字段：

```json
{
  "id": "r...",
  "ts": "2026-11-15T09:12:00.000Z",
  "kind": "photo",              // photo | text
  "thumb": "data:image/jpeg;base64,...",   // 256px 缩略图，原图不入库
  "mood": { "phi": 45, "r": 0.6, "valence": 0.4, "arousal": 0.5,
            "anchor": "喜", "label": "偏雀跃·中等", "color": "#f2cf96" },
  "facts": { ... },             // 就是 observe 返回的那个对象
  "note": "…", "reply": "…", "question": "…",
  "draft": "…", "final": "…",
  "chat": [ { "role": "me", "text": "…" } ]
}
```

右上角「⋯」菜单里有 **导出 JSON / 从 JSON 导入 / 清空全部**，可以直接拿一份样本数据看。
如果之后要做云同步，把这份 JSON 原样上传即可。

## 六、已知限制

- **单文件 6.3 MB**：离线分发很方便，但线上跑要整包解析。如果要部署到服务器，建议拆成 `index.html + app.css + app.js + assets/`，图片从 base64 改成独立文件。
- **localStorage 上限约 5 MB**：存满会提示「存储满了，先删几条旧记录」，不会静默丢数据。
- **封面标题是书法体子集**：只包含「光影志」三个字，已内嵌。如果要改标题文字，新字会回落到宋体——需要重新做一次字体子集（做法见 README 第十三节）。
- **「接入真实模型」按钮是禁用的**：那是演示时的诚实标注，接了后端可以删掉那个面板（搜 `statusSheet`）。
