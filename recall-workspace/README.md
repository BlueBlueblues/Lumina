# 光影志 · 证据回忆工作台（核心版本）

入口：回看 → 聊着找。保留原站视觉与记录流程，工作台采用 Vue 3、Vite、TypeScript 构建。

## 已实现

- 模型使用真正的 Function Calling 决定本地 `search_memories` 和 `get_memory` 调用；浏览器执行，结果回传后端后继续决策。
- 最多4轮工具决策、每轮最多4个请求、最多读取6条记录；会话最多32个，空闲约10–11分钟后清理。成功结束立即移除；不把查询和候选正文写入数据库。
- 人物、场景等短词 OR 召回，支持日期范围；允许模型放宽检索。当前是关键词/结构化召回，尚未接入向量语义索引。
- 用户原话、用户补充、用户对话、自选心情、记录日期、AI 图像观察、AI 改写分别标注来源。AI 图像观察与改写不能充当用户原话证据。
- 每条线索与候选对勘：支持、明确冲突、未知。程序验证记录与字段、逐字引文；另一次模型调用核验语义。不通过者降为未知。
- 程序依据对勘差异生成澄清问题和选项，避免引入“独自一人”等原文未提供的选项；用户调整后从新的 Function Calling 会话重新检索。
- 展示原文、引用、当前线索、候选和真实执行轨迹；无答案和模型错误明确反馈，不伪装成成功。
- 合成案例只在工作台内存中使用；不导入、覆盖或同步用户日记，也不预设模型结果。
- 主站通过明确的记录变更事件接入同步桥，不再覆盖 `Storage.prototype.setItem`。
- 照片观察接口改用已经生成的1280px图片；存储列表继续使用256px缩略图。

cd /opt/lumina/recall-workspace

npm test
npm run build
cd /opt/lumina/backend
npm test

工作台构建输出位于 `frontend/recall-assets`。当前资源使用版本查询参数更新缓存；修改发布内容时同步更新 index.html 中的资源版本。`npm run build` 包含生产构建产物的 DOM 挂载检查，防止 Node 全局变量泄漏到浏览器运行时代码。

## 数据与边界

检索在本地执行。搜索命中摘要和选定候选文字会经过自家后端发送给模型；不因此开启云同步，不上传照片。服务端短时会话只在内存中保存必要上下文。

检索线索的纠正不修改原始日记。系统核对的是“记录与线索是否一致”，不宣称能恢复客观真相。逐字校验不能证明语义支持；语义核验仍会出错，用户需要检查原文。

历史云同步记录可能缺少完整原始对话；没有用户原话的细节保留为未知。此版本未迁移同步数据库以保存全部原始对话，避免把旧的生成文本倒填成“原始证据”。

本版本未完成全站 Vue 迁移、真实 token 流式输出、向量语义召回、完整100条/60问基准、用户实验、素材授权或HTTPS配置。它交付的是核心证据回忆流程，不能据此宣称冠军级性能或已验证原创性。
